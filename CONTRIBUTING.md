# Contributing to Decipher AI

## How to Contribute

1. **Fork** the repository and clone locally
2. Create a **feature branch**: git checkout -b feat/your-feature
3. Make your changes and write **clear commit messages**
4. Push and open a **Pull Request** to main

## Commit Message Convention

We use [Conventional Commits](https://www.conventionalcommits.org/):

- eat(scope): description — new feature
- ix(scope): description — bug fix
- style(scope): description — CSS/formatting only
- docs: description — documentation
- chore: description — maintenance tasks

## Code Style

- Use **ES Modules** (import/export)
- Keep functions **small and focused**
- Add **JSDoc comments** for exported functions
- Use **semantic HTML** and accessible attributes (ria-*)

## Reporting Bugs

Open a GitHub Issue with:
- Steps to reproduce
- Expected vs actual behaviour
- Browser and OS version
